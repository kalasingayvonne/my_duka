# MyDuka 🛒

A shop management system built with Flask and PostgreSQL that tracks products, sales, and stock for small retail businesses.

## Features
- Add and manage products
- Record sales and view sales history
- Track stock additions per product
- Dashboard with sales and profit summaries

## Tech Stack
Python · Flask · PostgreSQL · Bootstrap 5 · Jinja2

## Setup
\`\`\`bash
git clone https://github.com/kalasingayvonne/myduka.git
cd myduka
pip install -r requirements.txt
python main.py
\`\`\`

## What I learned
Building this taught me how to connect Flask routes to a PostgreSQL database, structure Jinja templates with inheritance, and debug real errors like route conflicts and missing form data end-to-end.
